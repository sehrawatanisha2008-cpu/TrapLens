# TrapLens

TrapLens is an interactive cybersecurity awareness and scam investigation platform designed to help users identify suspicious links, scam patterns, and online red flags.

## Features

- URL trust score analysis
- Suspicious keyword detection
- Scam pattern identification
- Interactive scam simulation
- Response-time based scam awareness test
- Cyber safety learning section
- Scam intelligence case studies

## Tech Stack

- HTML
- CSS
- JavaScript

## Purpose

TrapLens focuses on digital safety, scam awareness, and helping users understand why certain online links or messages may be risky.
